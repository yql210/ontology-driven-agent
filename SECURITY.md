# Security Policy

## Reporting a Vulnerability

Please do not report suspected vulnerabilities through public issues, discussions, or pull requests.

A dedicated security contact is not currently published. Report the issue through a private maintainer channel. If you do not have one, use the repository hosting platform to ask a maintainer for a private reporting path without disclosing the vulnerability details publicly.

Include a clear description of the issue, affected versions or configurations, reproduction steps or a proof of concept when available, and any suggested mitigation.

## Handling Reports

Maintainers will assess reports, coordinate a fix when appropriate, and decide when disclosure is safe. Please allow reasonable time for assessment and remediation before public disclosure.

## Supported Versions

No separate supported-version matrix is currently published. Reports affecting the current development version are welcome.
